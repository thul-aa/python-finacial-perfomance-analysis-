# Financial Performance Analysis

A pandas-based analysis of company sales data, covering revenue, expenses, 
and regional performance trends.

## What it does
- Loads and cleans raw sales data (handles currency symbols, thousands 
  separators, and inconsistent date formats)
- Analyzes revenue and expenses by region and month
- Identifies highest/lowest performing months
- Visualizes trends with charts

## Tools
Python, pandas, Google Colab
